# 水浒传复刻

世嘉 MD《水滸傳》（台湾川普科技，1996）的非官方网页复刻，手机浏览器就能玩。

原作的调研资料见 [docs/research.md](docs/research.md)，ROM 数据格式见 [docs/rom-notes.md](docs/rom-notes.md)。

## 两种模式

**原版模式（有原版 ROM 时）**

画面、地图、人物、头像、字库、对话、剧情脚本全部从玩家自己的 ROM 里实时读取，仓库里不带任何原版数据。

- 标题画面：星空往下卷到山景，「開始遊戲 / 繼續遊戲」，都是原版的图。
- 第一章：晁盖家 → 郓城县 → 醉龙轩 → 街头救燕青 → 官府追捕 → 投奔史家村。原版的事件脚本由复刻版里的脚本解释器执行，NPC 台词随剧情变化。
- 可以进屋、翻柜子（伤药、体弱香、银两），和所有村民对话。
- **战斗还在移植**：剧情走到开战时先显示胜负条件，然后当作打赢了继续剧情。
- 存档单独放，不和旧版混在一起；在 claude.ai 上会同步到云端。

目前只核对过丁丁机的简体修改版（`水浒传 (简) (147201688繁转简).md`，CRC32 `EB8759C0`）。在 claude.ai 里打开游戏页面时会自动读取存在页面里的 ROM；其它地方打开可以在标题画面点「导入 ROM」。

**旧版试玩（没有 ROM 时）**

用代码画的临时素材做的第一章「史家村」：村庄探索、第一战「史家村之战」（职业相克、反击、地形、升级转职、敌军 AI）。原版模式的战斗移植好之前，想玩战棋可以先玩这个。

## 操作

| 功能 | 手机 | 键盘 |
|---|---|---|
| 移动、移动光标 | 方向盘，或直接点地面、格子 | 方向键 / WASD |
| 确定、对话、调查 | A 键，或直接点人物、选项 | Enter / 空格 / Z |
| 取消 | B 键 | Esc / X |
| 菜单 | 「菜单」键 | C / M / Tab |

战斗中的操作：

- **行动**：点我方人物，再点蓝色格子移动，然后选「攻击」。点敌人会显示攻击预测，再点一次同一个敌人就出手。
- **查看敌人范围**：点敌人，会用红色标出它下回合能打到的格子。
- **结束回合**：点空地打开战斗菜单，选「结束回合」。

## 移植进度

| 部分 | 状态 |
|---|---|
| 标题画面、地图、人物行走图、头像、字库、对话框 | 原版 |
| 事件脚本（80 条指令） | 地图剧情用到的已经能跑，第一章全程通过 |
| NPC 对话、调查道具、旗标改地图 | 原版 |
| 战斗 | 找到了单位数据、36 场战斗的敌人配置和胜负判定，正在移植 |
| 世界地图、商店、队伍和装备菜单 | 还没做 |
| 音乐 | 还没做（原版是 68000 驱动的 FM 音乐） |

旧版试玩里的职业、相克、第一战配置是按攻略资料猜的，原版模式的战斗会改用 ROM 里的真实数据。

## 开发

需要 Node.js 20 以上。

```bash
npm install
npm run dev             # 本地开发服务器（手机和电脑在同一局域网时，用手机打开显示的地址）
npm test                # 单元测试：战斗规则、地图数据、第一战难度
npm run build           # 打包成一个 HTML 文件：dist/index.html
npm run build:artifact  # 另外生成 claude.ai Artifact 用的页面：dist/artifact.html
```

目录：

```
src/engine/   引擎：画面缩放、输入、界面、音效、存档
src/rom/      读原版 ROM：图块、地图、人物、头像、字库、消息、旗标补丁（纯逻辑，有测试）
src/orig/     原版模式：标题、地图场景、对话框、脚本解释器
src/art/      代码生成的临时美术：人物、图块、标题画面、毛笔字
src/data/     职业、道具、人物、地图、战斗配置
src/battle/   战斗规则（纯逻辑，有测试）、AI、战斗画面
src/field/    村庄探索画面
src/story/    剧情脚本
tests/        单元测试
tools/        标题字形提取、Artifact 页面转换；tools/rom/ 是 ROM 分析工具（见其中的 README）
docs/         调研资料
```
