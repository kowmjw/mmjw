# 水浒传复刻

世嘉 MD《水滸傳》（台湾川普科技，1996）的非官方网页复刻，手机浏览器就能玩。目前是第一章「史家村」试玩版。

原作的调研资料见 [docs/research.md](docs/research.md)。

## 现在能玩到的内容

- **标题画面**：照原版构图，有开始游戏和继续游戏两项。
- **史家村**：可以自由走动、和村民对话，进屋翻柜子、罐子找道具（弓术指南、伤药、疲倦草）。
- **第一战「史家村之战」**：回合制战棋，有职业相克、反击、地形加成、升级转职和敌军 AI。
- **结局**：战后剧情里李逵加入队伍，从南边村口出村，试玩结束。
- **存档**：
  - 3 个手动存档，外加 1 个自动存档，可以导出、导入。
  - 在 claude.ai 上打开时，会同步到当前玩家私有的云端存储。

## 操作

| 功能 | 手机 | 键盘 |
|---|---|---|
| 移动、移动光标 | 方向盘，或直接点地面、格子 | 方向键 / WASD |
| 确定、对话、调查 | A 键，或直接点人物、选项 | Enter / 空格 / Z |
| 取消 | B 键 | Esc / X |
| 菜单 | 「菜单」键 | C / M / Tab |

战斗中的操作：

- **行动**：点我方人物，再点蓝色格子移动，然后选「攻击」。点敌人会显示攻击预测，再点一次同一个敌人就出手。
- **查看敌人范围**：点敌人，会用红色标出它下回合能打到的格子。
- **结束回合**：点空地打开战斗菜单，选「结束回合」。

## 哪些照原版，哪些是临时的

**按攻略资料还原的**

- 职业和转职路线，比如刀客 → 大刀师 → 刀神、拳师 → 气功师。
- 部分职业相克：枪克渔人，刺客克枪、炮、弓，渔人能抵抗法术。
- 弓术指南的效果：命中 +10%。
- 史家村道具的位置：左上角房屋有弓术指南，右下角房屋有伤药。
- 第一战的敌人构成（渔人、刀客、拳师）和胜负条件（击败李逵胜利，晁盖撤退失败）。

**临时的，以后换成原版**

- 人物和地图的像素图。
- 台词。
- 具体数值，以及资料里没提到的相克关系。
- 地图布局。
- 音乐。现在只有合成的音效。

这些都要从原版 ROM 里提取，详见 [docs/research.md](docs/research.md)。

## 开发

需要 Node.js 20 以上。

```bash
npm install
npm run dev             # 本地开发服务器（手机和电脑在同一局域网时，用手机打开显示的地址）
npm test                # 单元测试：战斗规则、地图数据、第一战难度
npm run build           # 打包成一个 HTML 文件：dist/index.html
npm run build:artifact  # 另外生成 claude.ai Artifact 用的页面：dist/artifact.html
```

目录：

```
src/engine/   引擎：画面缩放、输入、界面、音效、存档
src/art/      代码生成的临时美术：人物、图块、标题画面、毛笔字
src/data/     职业、道具、人物、地图、战斗配置
src/battle/   战斗规则（纯逻辑，有测试）、AI、战斗画面
src/field/    村庄探索画面
src/story/    剧情脚本
tests/        单元测试
tools/        标题字形提取、Artifact 页面转换
docs/         调研资料
```
