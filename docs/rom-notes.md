# 原版 ROM 数据格式笔记

分析对象：`水浒传 (简) (147201688繁转简).md`，2MB，CRC32 `EB8759C0`，SHA-1 `94a360cd2121a23d4d600dcc89634a2989ac016f`。
这是丁丁机的修改版（打一次升一级、钱最多，繁转简）。原版繁体 ROM 的偏移可能不同，下面的地址只对这个文件核对过。

ROM 本身不进仓库（`/rom/` 在 .gitignore 里）。分析工具在 `tools/rom/`，用法见 `tools/rom/README.md`。

## 总体

- 没有标准 MD 头：$100 开始是 `SEGA` 然后直接是代码。复位入口 $0004BA，栈 $FFFFF0。
- 图形数据基本都是**未压缩**的 4bpp 图块（每块 32 字节）。
- 图块载入函数 $0E50：从 a2 开始把字写进显存（起始图块号 d0），遇到字 `0x3402` 结束。
- 画版面 $1028（写 A 层 $C000）/ $1060（写 B 层 $E000）：a2 = 版面字数组，(d0,d1) = 起点格，d2+1 = 宽，d3+1 = 高，每行 64 格。
- 调色板 $2D38：a2 = 颜色表，d0+1 = 个数，d1 = 起始序号；先写进 $FFEF00，再淡入。
- 颜色是 MD 格式 `0000 BBB0 GGG0 RRR0`。

## 地图

地图编号是一个字：高字节 = 组（0–12），低字节 = 组内序号。四张表都按 `[组][序号]` 两级指针索引：

| 表 | 地址 | 内容 |
|---|---|---|
| 排版 | $0293EA | 三段 RLE：上层（写到 $FFB000，目前全是空的）、地面（$FFC000）、属性（$FFD000） |
| 大块定义 | $0770A6 | 每块 32×32 像素 = 4×4 个版面字（32 字节），行优先 |
| 图块 | $032182 | 载入到显存 0x200 号图块起 |
| 调色板 | $0DD744 | 32 色（第 0、1 行） |

入口表 $0DE088：`[组]` 指针 + 序号×16，16 字节一条：`宽 高 宽 高 镜头X 镜头Y 主角X(字) 主角Y(字) 朝向 ? ? ? ?`。地图宽高要从入口表里查（排版数据本身不带宽度）。

RLE 解压（$2DC6）：`F0` 切到单字节模式，`F1` 切到双字节模式；`00–EF` 原样输出；`F2–FE` 低 4 位是重复次数，后面跟 1 个（或 2 个）字节；`FF n` 重复 n 次，`FF 00` 结束。

属性层每格一个字节（$0D30 / $0D92 / $0DF4 这几段走路代码）：

- `00`：能走
- `01–4F`：能走，踩上去触发事件（事件编号 = 这个值）
- `50–7F`：挡路；`51–7F` 撞上去触发事件，`70` 是普通墙
- `80–AF`：挡路，面对它按 A 触发事件（柜子、罐子等）

主角一步走 32 像素（一个大块），每帧 2 像素。一屏 10×7 个大块。朝向 $FFE006：0 上、1 下、2 左、3 右。

## 事件脚本

- 事件表 $0E2DE2：`[组]` → 这一组的脚本块；块开头是按事件编号排的字偏移表，脚本地址 = 块地址 + 偏移。
- 旗标在 $FFE200 + 组×4（每组 32 位）。`op21 组 位` 置位，`op22` 清除，之后调用 $1C5AC。
- $1C5AC 按组分派到写死的代码（表 $1C5F2），根据旗标改属性层的事件格。例如地图 0x106（晁盖房间）门口 (4,8)(5,8) 是事件 0x42，组 1 旗标第 0 位置位后清掉。
- 解释器在 $FD1A：每条指令先是一个字（指令号 0x00–0x4F，表 $FD46），`FF FF` 结束。
- 新游戏开场脚本在 $0E2FF0。

已经弄清的指令（参数字节数不含指令号本身）：

| 指令 | 参数 | 作用 |
|---|---|---|
| 0d | 表 | 按 $FF6158 取第 n 个标签字，往后找同样的字，从那里继续 |
| 0e | 标签字, 方向字 | 方向 0 往后找标签，否则往前找 |
| 12 | 地图字, 入口字 | 设地图和入口，读入口表 |
| 13 | – | 重新载入整张地图 |
| 19 | 首槽, 个数 n, n×(X字,Y字), n 字节（补齐偶数） | 让几个人物同时走到指定位置 |
| 1d | 消息号字 | 显示对话 |
| 1e | 字 | 设 $FFE10D |
| 1f | 槽, 值 | 设人物槽的朝向/动作 |
| 20 | 方向字 | 主角朝这个方向走一步 |
| 21 / 22 | 组, 位 | 置位 / 清除旗标 |
| 23 | (槽字, 8 字节)… 直到槽 > 15 | 放人物 |
| 24 | 槽字 | 删掉人物 |
| 25 | 地图字, 宽, 高, 镜头X, 镜头Y | 换地图 |
| 26 | 字 | 加入队伍（$FFE610 列表） |
| 28 | 2 字节 | 设 $FF601C / $FF601B |

人物槽在 $FFE000 + 槽×16（16 个槽，0 号是主角）；$FF601E 是在用的槽的位图。战斗单位表在 $FFE780，每个 64 字节，最多 30 个。

## 消息（对话）

- 消息表 $0BC6E4：510 条指针。
- 一条消息由若干段组成：`[头像号][文字…] FF [续]`，续 = `FF` 表示后面还有一段（换人说话），`00` 表示结束。
- 头像号 0 表示没有头像；否则头像 = 头像表[头像号 − 1]。
- 文字码：`00–EF` 当前字库页里的字；`F0–FB` 切换字库页；`FC` 切换红色高亮；`FD n` 等待/速度；`FE` 换行。每行 16 个字，每页 3 行。

## 字库

- 分页表 $0AE2A4：8 页，每页 240 个字，每字 32 字节。
- 16×16 单色点阵，按 左上、右上、左下、右下 四个 8×8 块存，每块 8 字节，最高位在左。
- 字的顺序是游戏里第一次出现的顺序（第 0 页开头是 戒刀 青铜剑 玄铁八环 七星……），要自己做对照表。

## 人物行走图

- 指针表 $100000：79 套（0 和 1 都是晁盖）。
- 每套 11 帧，每帧 32×32（4×4 个图块，**按列**排列），512 字节。
- 帧 0–2 朝下，3–5 朝上，6–8 朝左（朝右用左的镜像），9、10 另作他用。
- 走路动画序列（$138E）：朝下 1,0,1,2 → 帧 0/1/0/2；朝上 3/4/3/5；朝左、右 6/7/6/8。
- 所有人物和头像共用一套调色板（第 2 行），在 $0175C8。

## 头像

- 指针表 $160000：78 个，指向 40 张不同的图（很多路人共用）。
- 每张 48×48 = 6×6 个图块，按列排列，1152 字节。用人物调色板。
- 0 晁盖，23 阿福（这版消息里阿福的头像号是 0x18 = 24，减 1 就是 23）。

## 音乐

$1D8000 起是音乐数据，驱动在 $1E4000 起（68000 自己播放）。还没分析。

## 调查结果、道具、系统文字

- `op16 n`：n > 0xFF 是找到钱，金额表 $1AAB2（第 n&0xFF 项，32 位）；否则是道具号，放进背包 $FFE400（道具号）/ $FFE480（数量），最多 128 种。
- 道具名表 $0AD17C：按道具号取字偏移，字串以 FF 结束（只有切页码，没有换行）。0x80 伤药、0x81 雪山参……0x8B 体弱香；0x01 起是武器（戒刀、青铜剑……）。
- 系统文字表 $01A6FC（指针）：0–9「获得一百两」到「获得十万两」，10「获得」，16「敌方全灭」，17「晁盖或燕青死亡」，18「取得麻沸草」等。

## NPC

- NPC 表 $0DC9D0：`[组][序号]` → 16 字节一条，到首字节 0 为止：`人物号 姿势 X(字) Y(字) 移动方式 对话号 范围x1 y1 x2 y2(字)`。移动方式 FF 不动，FE 原地转身，其它在范围里走动。
- 进地图时按可见位图把可见的 NPC 依次放进 8–15 号槽（$18198）。位图：表 $18232 列出的地图用 RAM $FFE2C0 的字（初值从 $1828C 拷），其它地图全部可见。
- 跟 NPC 说话（$182AA）：头像 = NPC 的人物号；消息 = 表 $0DEB4C[对话号] 指向的指针数组的第「对话进度」项（进度在 $FFE300 + 对话号，脚本 op2c 加一）。消息第一个字节是对话号本身，后面才是文字。

## 剧情动画

- `op19`：直线走到像素位置（可以斜走），每帧 1 像素（节奏 1）；每个人物一个「走完后的姿势」字节。
- `op1a 首槽 个数 字… 字节…`：按格子走，先横后竖，每步 32 像素，只处理 0–7 号槽；字的高字节是列、低字节是行，0xFF 当 -1（走出地图）。
- `op1f 槽 姿势`，姿势 = 朝向×4（0 上 4 下 8 左 12 右）。
- 行走动画每 16 帧换一步（节奏 1；op1e 设成 2、4 会更快）。

## 战斗

- `op32 n` 设下一场战斗的编号（RAM $FFE10F，新游戏时是 0），`op25 地图 宽 高 镜头X 镜头Y` 进入战斗。
- 战斗配置表 $1C98A：36 场，每场 `[首个单位槽][个数][个数×64 字节单位记录]`，拷到单位表 $FFE780 + 槽×64。0–11 号是我方，12–29 号（$FFEA80 起）是敌方。
- 单位记录 64 字节（已确认的部分）：`+00 人物号`、`+01 姿势`、`+02 X`、`+04 Y`、`+10 等级`、`+12 当前 HP`、`+14–1B 各项能力`、`+1F 最大 HP`、`+20 职业`。
- 胜负判定表 $120E8：36 段代码，每段检查条件后用 `move.b #事件号,d2 / jsr $14144` 触发本组的事件。惯例：0x44 失败，0x45（或 0x25、0x30…）开场，最后一个是胜利。第一战：晁盖阵亡或燕青不在 → 0x44，全灭敌军 → 0x46。
