# MD《水滸傳》复刻研究报告

> 调研日期：2026-09-24。当时的会话环境只能访问 GitHub，其它网站都被网络策略拦截，下面的内容是用搜索引擎摘要交叉比对整理出来的。标「待核实」的地方需要用原版 ROM 或实机游玩确认。

## 1. 游戏身份

| 项目 | 内容 |
|---|---|
| 名称 | 《水滸傳》（英文资料写作 *Shui Hu Zhuan*） |
| 平台 | 世嘉 Mega Drive / Genesis（MD），非官方授权卡带 |
| 开发 | 川普科技（Chuanpu Technology），台湾 |
| 发售 | 1996 年，台湾（少数资料写 1995 年） |
| 类型 | 战棋 + RPG：平时在村镇里走动、对话、搜东西，战斗是回合制战棋，和光荣《三国志英杰传》是同一类 |
| 语言 | 繁体中文；后来有玩家做的简体中文版、「音频修正最终版」（2023-01-07 发布）、无限升级版等修改版 |
| 存档 | 标题画面有「開始遊戲 / 繼續遊戲」，应该是卡带电池存档（待核实） |

容易混淆的同名作品（都**不是**这一款）：

- 《水滸風雲傳》：MD，1996 年，Never Ending Soft Team 开发，横版清版动作游戏。2015 年 Piko Interactive 以 *Water Margin: A Tale of Clouds and Wind* 为名重新发行。
- 光荣《水浒传·天导108星》《水浒传·天命之誓》、科乐美《幻想水浒传》系列。

川普科技的其它作品：《亞瑟傳說》（1995）、《太空戰士》（1996，英文版 *Brave Battle Saga*，Piko Interactive 取得版权后重新发行，并上架 Steam）、《封神英傑傳》（1996，也是战棋，和《水滸傳》共用部分素材，例如扈三娘的行走图就是改自《封神英傑傳》的主角林云）。

## 2. 玩法概要

- **两种模式交替**
  - 探索（RPG）：在村镇里走动、和 NPC 对话；房屋里的柜子、罐子可以搜出隐藏道具；有商店（例如「百货店」卖医书）。
  - 战斗（战棋）：格子地图，敌我轮流行动，每个单位移动后攻击或使用道具；每一关的胜负条件不同。
- **剧情**：以原著为底子，加了大量原创和奇幻内容（例如百花谷里有僵尸）。保留了智取生辰纲、西门庆与潘金莲、高衙内调戏林娘子等名场面，但结局改成梁山好汉除掉高俅、保住大宋江山的大团圆。
- **核心角色**：好几关的失败条件都是「晁盖阵亡」，晁盖应该是主角/队长（待核实）。
- **规模**：攻略网站有「第二十关」的图文攻略，所以至少有 20 场战斗（总数待核实）。

## 3. 已知的系统细节

### 3.1 前期关卡片段

| 地点 | 内容 |
|---|---|
| 史家村（应为第一战） | 敌方有渔人、刀客、拳师；胜利条件是击败李逵，失败条件是晁盖阵亡。村子左上角房屋里有「弓术指南」，右下角房屋里有「伤药」 |
| 百花谷 | 吴用打算扮成酒商、用迷药酒麻翻押送的士兵，需要百花谷的麻沸草。百花谷已经变成坟场，僵尸无限刷新；胜利条件是拿到地图最上方的麻沸草，失败条件是晁盖阵亡 |
| 黄泥岗 | 智取生辰纲 |

其它出现过的地名：青石县、玉安郡、桐林村、太智府（写法待核实）。

### 3.2 职业与转职

十几种职业，敌我双方都受职业相克影响，不同职业的攻击范围也不同。

两次转职（13 级、25 级）：

- 刀客 → 大刀师 → 刀神
- 策士 → 大军师 → 卧龙
- 郎中 → 神医 → 华佗
- 枪术师 → 枪甲士 → 金镂人
- 风水师 → 阴阳师 → 大真人

一次转职（19 级）：

- 渔人 → 水鬼
- 刺客 → 神行者
- 弓箭手 → 神射手
- 隐士 → 智者
- 拳师 → 气功师

另外还有炮手（铁炮手）、风筝人（和解珍有关）等职业，转职情况待核实。

### 3.3 相克与职业特点（玩家经验总结，待核实）

- 刺客：克枪客、炮手、弓手，伤害极高，后期常常一击必杀；但防御差，容易被围攻。
- 枪客：克渔人、卧龙、隐士、真人、医生，防御极高。
- 卧龙：对卧龙以外的职业都有不错的伤害。
- 气功师：血量高、攻击力最高，命中和闪避都好，打哪种职业都行。
- 渔人：攻击和防御都低，但能抵抗法术系攻击；转职后攻击范围仍然只是周围四格。
- 铁炮手：命中和闪避不错，攻防中等，移动力差；可以直线攻击到 4 格外。
- 有反击机制。

## 5. 复刻路线

| 路线 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| A. 模拟器套壳 | 模拟器 + ROM，再加上触屏和存档优化 | 最快，而且百分之百原味 | 算不上复刻，也不能公开分发 ROM |
| B. 重写引擎，读玩家自己的 ROM | 游戏程序自己写，素材在玩家本机从 ROM 里提取（ScummVM、OpenMW、devilutionX 都是这种做法） | 画面、手感都是原版的；代码完全是自己的，可以开源公开 | 要逆向 ROM 里的图像、地图、脚本格式，前期工作量大 |
| C. 全新素材重制 | 规则照搬原版，美术、音乐、台词全部重新做 | 可以公开发布，甚至可以商用 | 需要美术和音乐资源，内容量大 |

**建议走 B，同时把引擎做成素材可替换**：以后想走 C，只需要换一套素材包，引擎和数据格式都不用改。

## 6. 技术方案（建议）

- **语言和引擎**：TypeScript + Phaser，用 Vite 构建。Phaser 对 2D 场景、Tiled 地图、键盘/手柄/触屏输入和音频都有现成的支持。
- **为什么用网页技术**：手机浏览器打开就能玩，还能打包成 PWA、安卓/iOS 应用（Capacitor）和桌面版（Tauri 或 Electron）；ROM 可以在浏览器里本地解析，不用上传到任何地方；在云端开发环境里也能直接构建，并用 Chromium 自动测试。
- **画面**：逻辑分辨率 320×224（和 MD 一样），按整数倍放大，保持像素清晰。
- **文字**：原版字库从 ROM 里提取；新素材版用开源像素字体（方舟像素字体或缝合像素字体，都是 OFL 许可），用 OpenCC 做繁简切换。
- **数据驱动**：职业、人物、道具、关卡用 JSON；地图用 Tiled 编辑；剧情事件用一套简单的脚本（对话、选项、剧情标记、人物加入、获得道具、开始战斗）。
- **战斗逻辑**：寻路、攻击范围、相克、伤害、AI 都写成独立的纯逻辑模块，用 Vitest 做单元测试，数值和原版逐项对照。
- **存档**：多个存档位，存在 IndexedDB 里，可以导出和导入存档文件。
- **音乐**：原版音乐可以录成 VGM，在本机用 WASM 版的 VGM 播放库播放；要公开发布的版本改用重新编曲的音乐。

目录结构（草案）：

```
docs/          研究和设计文档
game/          游戏本体（TypeScript + Phaser）
data/          职业、人物、道具、关卡、事件数据
tools/rom/     ROM 分析和提取脚本
rom/  extracted/   原版 ROM 和提取结果，只放在本机，写进 .gitignore
```

## 7. ROM 分析计划

MD 硬件要点：CPU 是 68000；画面常用 320×224；图块是 8×8 像素、每像素 4 bit、每块 32 字节；4 组调色板、每组 16 色，颜色是 9 bit（`0000 BBB0 GGG0 RRR0`）；声音是 YM2612 FM 和 SN76489 PSG，由 Z80 驱动。

1. **确认版本**：算出 ROM 的 CRC32 和 SHA-1，区分原版和各种修改版（简体、音频修正、无限升级），以原版为准；再读 ROM 头（`$100`–`$1FF`）里的名称、大小、校验和和存档（SRAM）信息。
2. **图像**：按 MD 4bpp 格式扫描、导出图块和调色板，确认有没有压缩（常见的是各种 LZ 变体或厂商自己的格式）。
3. **字库和文本**：中文多半是 ROM 里的 16×16 点阵字库，文本存的是字库序号，而不是 Big5 编码。先导出全部字形，和参考字体做图像比对，自动生成「序号 → 汉字」对照表，再导出全部对白。
4. **数值表**：一边玩一边在模拟器里搜索内存（比如 HP 数值），设读取断点，顺着追到 ROM 里的职业表、道具表和敌人配置表。
5. **脚本和地图**：用 Ghidra（有现成的 MD ROM 加载插件）反汇编 68000 代码，弄清事件脚本的指令和地图格式。
6. **音乐**：用带 VGM 录制功能的模拟器把各首曲子录下来。

工具：Exodus、BlastEm、Gens KMod、MAME 的调试器（断点、内存和显存查看），YY-CHR 或 Tile Molester（看图块），Tiled（地图），Python 或 Node 脚本。

另外，《封神英傑傳》是同一家公司的同类型游戏，这套工具很可能可以直接复用。

## 8. 里程碑

- **M0 ROM 分析工具**：版本识别、导出图块和调色板、字库对照表、导出全部文本；整理出职业、人物、道具表的初稿。
- **M1 可玩的纵切片**：标题画面（開始遊戲 / 繼續遊戲）→ 史家村探索、对话、搜东西 → 第一场战斗 → 存档和读档，手机浏览器能玩。
  - 标题画面参考原版：「水滸傳」三个字是火焰纹理的书法字，带黑色描边和投影；背景是远山、平原和右侧岩壁；菜单两项，选中的一项是白到蓝的金属渐变，没选中的是灰色。
- **M2 完整的战斗系统**：全部职业和转职、相克、反击、地形、道具、敌人 AI、各种胜负条件和增援。
- **M3 全部内容**：所有城镇、事件、战斗、隐藏人物和结局。
- **M4 打磨**：原版音乐、触屏操作、繁简切换、倍速、设置菜单，打包成 PWA、安卓和桌面版。

## 9. 版权和仓库注意事项

- 《水浒传》原著早已进入公有领域，人物和故事都可以自由使用；但这款游戏的程序、美术、音乐和台词仍然受版权保护。川普科技的现状不明，不过同公司的《太空戰士》版权已经被 Piko Interactive 买下、重新发行，说明这批游戏的版权至今还有人持有。
- **本仓库（kowmjw/mmjw）是公开的**：不要把 ROM，或者从 ROM 提取出来的图片、音乐、台词提交进来。可以提交的是自己写的引擎代码、工具脚本、自己整理的数值规则和自制素材。
- 数值和规则一般不受版权保护，但原版台词不要照搬进公开仓库，改成运行时从玩家自己的 ROM 读取。
- 如果需要在云端会话里分析 ROM，可以把它放进一个单独的**私有**仓库，再挂载到会话里读取。
